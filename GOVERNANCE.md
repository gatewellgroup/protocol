# Governance

## Who publishes the Protocol

The Gatewell Protocol for Origin Evidence is published by Gatewell Group LLC, a Los Angeles compliance consultancy that also sells services assembling and verifying evidence files under it. The text says so on its cover, and the Protocol's own Part V separates the people who assemble a file from the people who verify it. The comment process below runs in public so that the standard's content is answerable to the people who use it.

## Source of truth

The canonical text lives at https://gatewellgroup.com/protocol/v1.0/. This repository is a one-way export of the published edition. A pull request that changes the text is treated as a comment and answered with a disposition; it is not merged, because the text changes only at the source and is then re-exported.

## The comment period

Write to protocol@gatewellgroup.com. A comment that can be acted on gives the clause number, the change proposed and the reason for it. Give your name and affiliation, and say whether the comment may be published with them. By submitting a comment you agree that Gatewell Group may incorporate it into the Protocol and publish it as you have permitted.

Each comment is logged with a number and the date received. Comments are published on this page with the commenter's permission. Every comment receives a written disposition: accepted, accepted in part, or declined with the reason. The disposition table is published with the final text of Version 1.0.

The questions put for comment are listed in `comment-period/README.md` and opened as issues in this repository, one per question, so that discussion of each has a public thread. A comment on any other clause may be opened with the comment form.

## Versions and releases

Version 1.0 is a public comment draft. Draft revisions are numbered (Revision 1, 2, 3) and each is recorded in Annex G and in `CHANGELOG.md`. The versioned URL https://gatewellgroup.com/protocol/v1.0/ does not change once Version 1.0 is final; a later version gets its own URL. Each release of this repository is archived through Zenodo, which assigns a version DOI under one concept DOI for the Protocol; the DOI of the current release is recorded in `CITATION.cff` and on the published page.
