- **Title:** The Gatewell Protocol for Origin Evidence, Version 1.0 (Public comment draft, Revision 3)
- **Author:** Ilya Tsimerinov, Principal, Gatewell Group LLC (SSRN requires a person; the organisation goes in the affiliation)
- **Date written:** 2026-09-17
- **Abstract:** The Gatewell Protocol for Origin Evidence, Version 1.0, is an open documentation standard for the evidence file behind a claim about where equipment and its components were produced and by whom. It covers the Origin Evidence File, three conformity levels, verification methodology, change control and Annexes A to G, with clause anchors. The Protocol states what a manufacturer's Origin Evidence File contains for a product line, the three conformity levels a buyer can ask for (Documented, Verified, Monitored), the verification methodology an independent examiner follows, change control on the file over the life of the product, and the annexes that carry the officer attestation, the bill-of-materials origin schema, the supplier declaration forms and the change record. Version 1.0 is a public comment draft, revision 3, open for public comment through October 31, 2026. Regime profiles apply the same file to Section 889, Build America, Buy America, and three defense procurement regimes. The text is licensed CC BY 4.0; Annex B in machine-readable form is CC0 1.0.
